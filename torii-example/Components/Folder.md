# "Folder" Component

- View, Edit

Every directory in the workspace is a "Folder". It is a container of multiple records which are called "folder contents". Folders are created by dragging and dropping records into other records. 

- The component can include other records of arbitrary type.

For example I have a unique card deck specifically for my world which I call the "Crown Cards", they consist of 80 cards, and while in theory I could make 80 records, it's most simple to simply put an article and define everything there. 

Or perhaps if I want to define the alphabet for a "constructed language", I could simply include the characters in the folder.
